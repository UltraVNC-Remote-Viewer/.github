# UltraVNC - Remote Viewer, Server Session, and File Transfer

## About UltraVNC

UltraVNC is a VNC server and viewer for a machine you may control. UltraVNC Remote Viewer is the client window. UltraVNC Server Session is the service on the host. UltraVNC Screen Share is the framebuffer you see. UltraVNC File Transfer is the optional file channel. UltraVNC Repeater Link is an intermediate you use only if your architecture already has one.

On the host you administer, run UltraVNC Server Session with a password the process allows. From your console, open UltraVNC Remote Viewer to that host. Use UltraVNC Screen Share for the actual work. Use UltraVNC File Transfer for a named file, not a whole disk. Use UltraVNC Repeater Link only on a path you designed. This is not unattended access to strangers.

UltraVNC Remote Viewer, UltraVNC Server Session, UltraVNC Screen Share, UltraVNC File Transfer, and UltraVNC Repeater Link exist to operate a screen you already have permission to operate.

## Key Features of UltraVNC

- **Remote viewer as the client** – UltraVNC Remote Viewer is host, port, password. UltraVNC Screen Share then appears. UltraVNC Server Session must already be up. UltraVNC File Transfer is a menu after connect. UltraVNC Repeater Link is a different connect string you only use if documented.
- **Server session as the host side** – UltraVNC Server Session runs on the machine you administer. Service mode versus user mode is a process choice. UltraVNC Remote Viewer is useless without it. UltraVNC Screen Share is that session’s framebuffer. UltraVNC File Transfer rights follow how you set the server. UltraVNC Repeater Link does not replace a locked-down listener.
- **Screen share as the work** – UltraVNC Screen Share is why you connected. Lower color if the path is weak. UltraVNC Remote Viewer input should be obvious (who has the keyboard). UltraVNC Server Session should not be unattended on a kiosk you do not own. UltraVNC File Transfer is separate. UltraVNC Repeater Link only changes how you arrive.
- **File transfer as a named copy** – UltraVNC File Transfer is one file or a small set. Not a backup product. UltraVNC Screen Share can wait. UltraVNC Remote Viewer stays connected. UltraVNC Server Session must allow it. UltraVNC Repeater Link may make this slow; then copy another way.
- **Repeater link as architecture** – UltraVNC Repeater Link is for a designed hop. Write it down. UltraVNC Remote Viewer uses that address. UltraVNC Server Session registers as the process requires. UltraVNC Screen Share still the goal. UltraVNC File Transfer still optional. A repeater on a random VPS is not a plan.

## Quick Start with UltraVNC

1. **Host you administer** – Start UltraVNC Server Session with a password you will not paste into a ticket. Confirm the listener is not open to the world. From your console, UltraVNC Remote Viewer to that host. Confirm UltraVNC Screen Share. Ignore UltraVNC File Transfer. Ignore UltraVNC Repeater Link.
2. **Work, then disconnect** – Do the change. Close UltraVNC Remote Viewer. UltraVNC Server Session can stay if policy says the host should remain reachable, or stop if it should not. UltraVNC Screen Share should not sit idle. No UltraVNC File Transfer yet. No UltraVNC Repeater Link.
3. **Optional file** – Reconnect. UltraVNC File Transfer of a named file to a named folder. Check it on disk. Disconnect. UltraVNC Screen Share was only the vehicle. UltraVNC Remote Viewer closed. UltraVNC Server Session as before. Still no UltraVNC Repeater Link unless the design needs it.
4. **Repeater only if designed** – If the architecture uses UltraVNC Repeater Link, document host, id, and who may connect. Test UltraVNC Remote Viewer through it once. Confirm UltraVNC Screen Share. Confirm UltraVNC Server Session registration. Keep UltraVNC File Transfer off until the view is stable.
5. **Review** – Passwords rotated. UltraVNC Server Session not on unexpected interfaces. No leftover UltraVNC Remote Viewer. No mystery UltraVNC Repeater Link. UltraVNC File Transfer logs if policy wants them. UltraVNC Screen Share not a 24/7 kiosk unless that is the job.

## Who Will Like UltraVNC

- **Operators** – Break-glass UltraVNC Server Session on a jump you own, UltraVNC Remote Viewer, UltraVNC Screen Share, disconnect, UltraVNC File Transfer rarely, UltraVNC Repeater Link only if the platform already has it.
- **Admins** – Lab hosts with UltraVNC Server Session, inventory of who may use UltraVNC Remote Viewer, UltraVNC Screen Share, UltraVNC File Transfer policy, UltraVNC Repeater Link as a drawn hop.
- **Developers** – A VM they run, UltraVNC Server Session, UltraVNC Remote Viewer from the workstation, UltraVNC Screen Share, skip UltraVNC Repeater Link, skip UltraVNC File Transfer if a share exists.
- **Technicians** – Customer host they were asked to operate, UltraVNC Remote Viewer, UltraVNC Server Session already there, UltraVNC Screen Share, UltraVNC File Transfer of a log they were told to collect, no new UltraVNC Repeater Link.
- **Labs** – Pair programming on a machine in the room, UltraVNC Screen Share, UltraVNC Remote Viewer, UltraVNC Server Session local, no UltraVNC Repeater Link, UltraVNC File Transfer off.
